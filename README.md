# 🚀 Lusotec Landing Page

Landing page para **[lusotec.cl](https://lusotec.cl)** — actualmente mostrando una página "en construcción" con un diseño premium mientras desarrollamos el sitio completo.

## 🛠️ Stack Tecnológico

- **HTML5** — Estructura semántica con SEO optimizado
- **CSS3** — Diseño responsive con animaciones, glassmorphism y dark theme
- **JavaScript** — Sistema de partículas interactivo con canvas
- **Vercel** — Hosting y despliegue continuo (CI/CD)

## 📁 Estructura del Proyecto

```
lusotec-landing/
├── index.html          # Página principal
├── style.css           # Estilos y animaciones
├── script.js           # Sistema de partículas interactivo
├── assets/
│   └── logo-lusotec.png  # Logo de Lusotec
└── README.md           # Este archivo
```

## 🚀 Desarrollo Local

Simplemente abre `index.html` en tu navegador, o usa un servidor local:

```bash
npx serve .
```

## 📦 Despliegue

El proyecto se despliega automáticamente en **Vercel** con cada push a la rama `main`.

- **Dominio**: [lusotec.cl](https://lusotec.cl)
- **CI/CD**: GitHub → Vercel (automático)
